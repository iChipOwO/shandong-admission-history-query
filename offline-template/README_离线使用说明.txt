往届录取信息 电脑离线版 v1.0.0

使用方法：

1. 解压整个文件夹后双击 start.bat。
2. 不要直接双击 dist/index.html，因为浏览器 file:// 限制可能导致数据加载失败。
3. 如果窗口闪退，改为：
   - 右键 start.bat → 在终端中打开
   - 或打开 CMD 后进入目录运行 start.bat
4. 程序会启动本地服务，如果没有自动打开浏览器，请手动访问显示的本地地址（通常为 http://127.0.0.1:5177）。
5. 使用结束后，关闭启动窗口即可停止本地服务（或在控制台按 Ctrl+C）。

说明：

- 不需要 Node.js。
- 不需要联网。
- 本地报告/收藏保存在当前浏览器的本地存储中，清理浏览器数据会丢失。
- 本工具仅提供往届录取信息查询与整理，不提供录取预测。
