# 往届录取信息

山东普通类常规批第 1 次志愿 2023-2025 年往届录取/投档信息查询工具。项目面向山东考生和家长，提供离线可用的历史数据检索、学校信息、排名参考、收藏和志愿报告整理功能。

## 功能概览

- 按专业、学校、城市、位次和专业方向查询往届录取信息。
- 查看 2023-2025 年最低位次趋势与候选专业信息。
- 浏览学校排名、学科实力、学校详情和大学生活提示。
- 保存收藏专业，整理个人志愿报告。
- 生成用于外部 AI 工具辅助核查的提示文本。
- 支持 Android APK 和 Windows 电脑离线版使用。

## Android APK 使用方式

1. 下载发布页提供的 Android APK。
2. 将 APK 安装到 Android 手机或平板。
3. 首次打开后等待数据加载完成，之后主要查询功能可离线使用。

如果系统提示安装来源风险，请确认安装包来自本项目正式发布渠道。

## Windows 电脑离线版使用方式

1. 下载电脑离线版 zip。
2. 解压到一个普通文件夹。
3. 双击 `start.bat` 启动本地服务。
4. 浏览器会打开本地页面，之后在页面中查询。

不要直接双击 `dist/index.html`，离线版需要通过 `start.bat` 启动本地服务，否则部分数据加载和页面跳转可能无法正常工作。
